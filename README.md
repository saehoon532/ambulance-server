# 사설구급차 이송 콜 서비스

보호자가 이송 요청을 접수하면, 가입·승인된 서울·수도권 이송단에게 콜이 뜨고 **가장 먼저 수락한 이송단 1곳**이 출동하는 서비스입니다. (카카오T 배차 방식)

| 화면 | 주소 | 누가 |
|---|---|---|
| 이송 요청 접수 | https://ambulance-server.vercel.app | 보호자 |
| 진행 상황 | https://ambulance-server.vercel.app/track.html | 보호자 (접수 후 자동 이동) |
| 콜 받기 | https://ambulance-server.vercel.app/provider.html | 이송단 |
| 관리자 | https://ambulance-server.vercel.app/admin.html | 운영자 (관리자 비밀번호) |

> 생명이 위급한 응급상황은 **119**를 이용하세요. 119구급차는 무료이며, 이 서비스는 유료 **사설 이송**용입니다.

---

## 이송 요청이 처리되는 순서

```
보호자 접수 ─▶ 배차대기 ─▶ 이송단 "수락" ─▶ 배차완료 ─▶ 이송중 ─▶ 완료
                 │          (먼저 누른 1곳)
                 └─ 배정 전에는 보호자가 취소 가능 / 관리자는 언제든 취소
```

1. **보호자 접수** — 환자 정보·출발지·도착지·필요 장비·구급차 종류를 입력하면 접수번호가 나오고 진행 상황 화면으로 넘어갑니다. 진행 화면 주소에는 그 보호자만 아는 열쇠가 들어 있습니다.
2. **이송단에게 콜** — 승인된 이송단의 콜 화면에 4초마다 새 콜이 확인되고 소리·진동·알림이 울립니다. 수락 전에는 **요약만** 보입니다 (출발·도착 지역, 긴급도, 성별·나이, 이동 방법, 장비, 예상 요금). 이름·전화번호·상세주소·증상은 보이지 않습니다.
3. **먼저 수락한 1곳만 배정** — 여러 이송단이 동시에 눌러도 서버가 1곳만 통과시킵니다. 배정된 이송단에게만 전체 내용이 열립니다.
4. **보호자 화면에 배정 표시** — 업체명·담당자·전화번호·차량번호와 "이송단에 전화하기" 버튼이 뜹니다.
5. **진행** — 이송단이 "이송 시작" → "이송 완료"를 누릅니다. 출발 전 사정이 생기면 "콜 반납"으로 다시 배차대기로 돌릴 수 있습니다.

### 오래 대기 콜 알림
긴급 **3분** / 일반 **10분** / 예약 **30분** 동안 아무도 수락하지 않으면:
- 보호자 화면에 안내(119 · 다른 업체 직접 연락)
- 이송단 콜 카드에 "⏰ N분째 대기" 표시 + 재알림 문자
- 관리자 화면 경고 배너·소리 + 관리자 문자

콜 하나당 한 번만 알립니다. 점검은 보호자·이송단·관리자 화면이 서버에 물어볼 때 함께 하며(최대 1분에 1번), 외부 cron 서비스로 `GET /api/cron/stale?key=CRON_SECRET`을 불러도 됩니다.

## 요금 (법정 이송처치료)

「응급의료에 관한 법률 시행규칙」 제11조 및 [별표 3] (2026. 7. 13. 개정)

| 구분 | 의료기관·이송업체 등 | 비영리법인 |
|---|---:|---:|
| 일반 기본요금 (10km 이내) | 40,000원 | 26,600원 |
| 일반 추가 (1km) | 1,500원 | 1,000원 |
| 특수 기본요금 (10km 이내) | 95,500원 | 63,600원 |
| 특수 추가 (1km) | 2,300원 | 1,500원 |

- **할증 20%**: 평일 18:00~다음날 09:00, 토요일, 공휴일(일요일 포함) — 기본·추가요금에 각각 가산
- **대기요금**: 병원 도착 후 30분 경과 시부터 10분당 6,000원
- 이송거리는 환자가 **실제로 탑승한 거리**입니다.

접수 화면에서 구급차 종류·예상 거리를 넣으면 예상 요금이 바로 계산됩니다(야간·주말 할증 자동, 공휴일은 체크). 계산은 `public/fee.js` 한 파일을 서버와 화면이 같이 씁니다. 실제 요금은 탑승 거리·대기시간으로 정산되며, 10km 초과분의 1km 미만은 올림으로 추정합니다.

## 이송단 가입과 업체 확인

이송단은 `/provider.html`에서 업체를 검색해 가입하고, **관리자가 승인해야** 콜을 받을 수 있습니다. 가입할 때 아래 공공데이터로 자동 확인한 결과가 관리자 화면에 함께 표시됩니다.

| 자료 | 범위 | 확인 내용 |
|---|---|---|
| 서울 열린데이터광장 「서울시 민간구급차 현황」 Open API (`tvAmblInfoInqire`) | 서울 (보건소 등 통보사 제외) | 기관명·주소·전화 + **차량번호가 그 업체 등록 구급차인지 대조** |
| 행정안전부 「건강_응급환자이송업 조회서비스」 | 서울·경기·인천, 영업 중 | 인허가일·영업상태 |

- 서울 자료는 12시간마다 API에서 새로 받고, API가 안 되면 저장소의 `seoul-ambulances.csv`를 씁니다.
- 행정안전부 자료에는 서울 업체가 없어(2026-11 기준) 서울은 서울시 자료로 확인합니다.
- 목록에 없는 업체도 업체명을 직접 입력해 가입 신청할 수 있으며, 관리자가 허가증을 보고 승인합니다.

## 그 밖의 기능
- **응급실 실시간 남은 병상** — 국립중앙의료원 「전국 응급의료기관 정보 조회 서비스」 (접수 화면 6번 "도착지")
- **현재 위치로 출발지 입력** — 좌표 → 주소 변환(OpenStreetMap)은 서버가 대신 호출
- **관리자** — 이송단 승인·거절·정지, 전체 콜 현황, 콜 취소·삭제, CSV 내보내기

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `server.js` | 웹 서버(Express): 접수·배차·이송단·관리자 API, 저장소, 오래 대기 알림 |
| `transport-api.js` | 행정안전부 이송업 API + 서울시 자료를 합쳐 업체 검색·확인 |
| `seoul-ambulances.js` / `.csv` | 서울시 민간구급차 Open API(우선)와 CSV(대비) 읽기 |
| `er-api.js` | 국립중앙의료원 응급실 병상 API |
| `sms.js` | 솔라피(SOLAPI) 문자 발송 |
| `public/index.html`, `app.js` | 보호자 접수 화면 |
| `public/track.html`, `track.js` | 보호자 진행 상황 화면 |
| `public/provider.html`, `provider.js` | 이송단 가입·로그인·콜 받기 |
| `public/admin.html`, `admin.js` | 관리자 화면 |
| `public/fee.js` | 법정 요금 계산 (서버·화면 공용) |
| `public/common.js`, `style.css` | 화면 공통 도우미·디자인 |

**저장소**: Vercel에서는 Upstash Redis, 내 컴퓨터에서는 `data/db.json`에 저장합니다.

## 환경변수 (Vercel 프로젝트 설정 → Environment Variables)

| 이름 | 용도 | 상태 |
|---|---|---|
| `ADMIN_PASSWORD` | 관리자 화면 비밀번호 | 설정됨 |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | Upstash Redis | 설정됨 |
| `DATA_GO_KR_KEY` | 공공데이터포털 키 (응급실 병상 + 응급환자이송업) | 설정됨 |
| `SEOUL_API_KEY` | 서울 열린데이터광장 인증키 (민간구급차 현황) | 설정됨 |
| `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_SENDER` | 새 콜·재알림 문자 | 미설정 (없으면 화면 알림만) |
| `ADMIN_PHONE` | 오래 대기 콜 관리자 문자 받을 번호 (쉼표로 여러 개) | 미설정 |
| `CRON_SECRET` | 외부 cron 점검 주소 비밀값 | 미설정 |
| `STALE_MIN_URGENT` / `_NORMAL` / `_RESERVED` | 대기 알림 기준(분), 기본 3 / 10 / 30 | 기본값 |

키·비밀번호는 서버에만 있고 화면으로 보내지 않습니다. 저장소에 올리지 마세요.

## 배포

배포 주소: **https://ambulance-server.vercel.app** (Vercel 팀 `saehoon`, 프로젝트 `ambulance-server`)

Vercel이 GitHub에 자동 연결되어 있지 않아, **GitHub에 push해도 사이트는 바뀌지 않습니다.** Vercel CLI로 직접 배포합니다.

```bash
npx vercel deploy --prod --scope saehoon
```

> 이 폴더의 Git 커밋 작성자가 Vercel 팀 멤버가 아니면 배포가 막힙니다(`TEAM_ACCESS_REQUIRED`). 그럴 때는 `.git` 폴더를 뺀 복사본에서 배포하세요.

### 내 컴퓨터에서 실행 (개발용)
```bash
npm install
npm start      # → http://localhost:3000
```
`.env` 파일에 위 환경변수를 넣으면 같은 기능을 시험할 수 있습니다. 저장소가 없으면 `data/db.json`을 씁니다. `ADMIN_PASSWORD`를 비워 두면 내 컴퓨터에서는 관리자 화면이 비밀번호 없이 열립니다(인터넷 배포에서는 막힘).

## 운영 전 확인할 점
- 여러 이송업체에 콜을 중개하는 구조이므로 「응급의료에 관한 법률」(이송처치료, 환자정보 제공 동의 등) 검토가 필요합니다.
- 문자(SMS)가 꺼져 있으면, 이송단이 콜 화면을 켜 두지 않을 때 새 콜을 알 수 없습니다.
- 서울시 자료에는 이송업체 외에 구급차를 보유한 병원도 포함됩니다. 승인 시 이송업 허가 여부를 확인하세요.
- 환자 건강정보는 민감정보입니다. 수락 전 이송단에게는 요약만 보이며, 전체 내용은 관리자와 배정된 이송단만 봅니다.
